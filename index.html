Como a ligação total funciona — aviso honesto

O TradingView não libera leitura direta dos candles para site externo grátis. Por isso, a ligação total funciona por Pine Script + Alerta + Webhook. Neste app, cole o alerta real recebido. Para execução automática real em corretora, precisa de servidor + API da corretora — não roda só em página estática. No modo atual, a ligação é para teste em conta demo e não envia ordem real. Não é recomendação de investimento e não há garantia de acerto. Trading tem risco de perda.
